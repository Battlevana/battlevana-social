# battlevana-social
Social Media assets for BattleVana

## Automation
- `RUNBOOK.md` – instructions every scheduled run follows (build, review, reminders, publishing).
- `kit/` – post templates, fonts (Blanka, Open Sans OFL), logos, Vana cut-outs.
- `.github/workflows/spoilers.yml` + `scripts/fetch_spoilers.py` – fetch new spoilers and combos every 3 hours into the `spoilers` branch.
- `requests/cards.txt` – ask the Action to fetch any card by name.
